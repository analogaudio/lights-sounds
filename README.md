## Deploy to GitHub Pages
1. Create new repo: `analog-audio` 
2. Push this folder:
```
git init
git add .
git commit -m "Analog Audio site"
git branch -M main
git remote add origin YOUR_REPO_URL
git push -u origin main
```
3. In GitHub repo Settings > Pages > Source: Deploy from branch main / root
4. Site will be live at https://YOUR_USERNAME.github.io/analog-audio/
